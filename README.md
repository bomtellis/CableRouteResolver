# CableRouteResolver
Finds the best route for a cable from source to destination.

## Excel room asset comparison

Open **Tools → Compare Excel Room Asset Schedules...** to:

1. import two `.xlsx` or `.xlsm` workbooks;
2. select and map the main asset worksheet and its columns independently for
   each workbook;
3. optionally select an assembly-items worksheet, or explicitly choose
   **No assembly sheet**;
4. map one or more room names/codes on either side;
5. compare direct assets and assembly-expanded totals; and
6. export an Excel report with **Original A**, **Original B**, and
   **Differences** worksheets.
